Exercise: Django Introduction

This is an introductory Django project developed as part of my web development training.
The project uses PostgreSQL as its database management system.

Features:
- 'notes' App: Manage notes with attributes title, body, created_at and is_published.
- 'categories' App: Classify notes into custom categories.
- A single note can belong to multiple categories, and a category can hold multiple notes.
- A fully configured administrative panel to manage database entries.
